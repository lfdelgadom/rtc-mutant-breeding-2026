PRACTICE DATA SETS FOR PARTICIPANTS WITHOUT DATA
RTC RER5030, Experimental Design and Data Analysis for Mutant Populations

Each folder is one crop. The data are simulated, with realistic problems (missing values, outliers,
different environments, spatial trends). Read the README.txt inside each folder.

  chrysanthemum_mutants/  4 environments, 120 lines (4 parents, 116 mutants), 5 traits + flower colour. Vegetative crop, complete blocks.
  wheat_mutants/          4 environments (2 places x 2 years), 105 lines (3 parents, 102 mutants), 5 traits + lodging score + awn type.
                          Seed crop, partially replicated design (not every line in every block). Includes a real hail effect.
  bean_mutants/           3 environments (irrigated, drought, rainfed), 84 lines (3 parents, 81 mutants), 5 traits + seed coat colour.
                          Complete blocks. Includes real zeros (crop failure) and animal damage.

Which one to choose? Take the crop that is closest to your own work.
Start with the folder's README.txt, then run first_look.R.
