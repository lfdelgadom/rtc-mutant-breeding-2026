RER5030 training course - Day 2, afternoon: analysing designs and comparing means

1. Unzip this folder on your computer (do not work inside the ZIP file).
2. Open Day2_afternoon.Rproj in RStudio (double click).
3. Run 00_install_packages.R once, even if you did it this morning
   (it adds agricolae, car and lmerTest). All lines should show TRUE.

Exercises of this session (follow the lecture):
  Exercise5_anova_and_assumptions.Rmd   13:30 - 14:45  ANOVA of an RCBD, residual
                                         diagnostics, transformation, ANOVA of other designs
  Exercise6_mean_comparison.Rmd         15:00 - 16:15  LSD, Tukey, Duncan, Dunnett,
                                         statistical and practical significance

Homework (after the session):
  Exercise3_john_alpha.Rmd              an alpha-lattice, step by step
  Exercise4_wheat_row_column.Rmd        a resolvable row-column design (optional)

How to work: run each grey box with the green triangle, from top to bottom.
Replace the ___ in the lines marked # TODO. The # HINT line above tells you where to look.
Every part says what result you should get, so you can check yourself.
Write your findings at the end of each part. Knit only at the end, if time allows.

Keep everything in this folder. It is your own copy: updating the course project
with Git never touches it.

Files:
  Cheat_sheet_alpha_lattice.html   t, k, s, r in plain words (open in your browser)
  data/Durum_wheat_Algeria.csv             real durum wheat data (Exercises 5 and 6)
  data/wheat_Australia_2008_2009_7loc.csv  data for Exercise 4
