# 7 checks before you trust an answer

1. **Run it.** Code that was not run is a suggestion, not a result.
2. **Check the model against your design.** Which terms are fixed, which are random? Are blocks nested in replicates?
3. **Check the numbers.** Every number in a text must be in your R output.
4. **Check the functions.** Does the package and the function exist? Look at `?function`.
5. **Check the units and the traits.** t/ha or kg/plot? Which trait?
6. **Ask a second model.** Paste the code in another assistant and ask for errors.
7. **Keep your own record.** Save the final code and the prompt that worked.
