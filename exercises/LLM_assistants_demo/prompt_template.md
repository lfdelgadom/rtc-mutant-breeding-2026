# Prompt template for data analysis

**Role.** You are a statistician who helps a plant breeder. Answer in simple English.

**Design.** (type of design, replicates, blocks, number of genotypes, locations, years)

**Data.** Data frame `d`. Columns: (name, type, units for each column).
Note: (anything special, for example block names repeated in each replicate, missing values).

**Objective.** (what you want to know, for example the adjusted mean of each genotype)

**Task.** Write R code with (package). Give only code and one short explanation.
Do NOT invent numbers. If you are not sure, say so.

**Format.** Short comments in the code. One step per block.
