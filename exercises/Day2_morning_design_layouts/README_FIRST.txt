RER5030 training course - Day 2, morning: generating experimental designs

1. Unzip this folder on your computer (do not work inside the ZIP file).
2. Open Day2_morning.Rproj in RStudio (double click).
3. Open 00_install_packages.R and run it once (internet needed).
   All lines of the output should show TRUE. FielDHub takes a few minutes.
4. Open Exercise0_variance_and_SED.Rmd (about 20 minutes): variance, residual variance, SED and LSD.
5. Then Exercise1_generate_designs.Rmd. We run the first box together.
6. Exercise2_my_own_design.Rmd, for your own material, if time allows or as homework.

How to work: run each grey box with the green triangle, from top to bottom.
Replace the ___ in the lines marked # TODO. The # HINT line above tells you where to look.
Write your findings at the end of each file. Knit only at the end, if time allows.

Keep everything in this folder. It is your own copy: updating the course project
with Git never touches it.

Files:
  Cheat_sheet_alpha_lattice.html   t, k, s, r in plain words (open in your browser)
  data/uniformity_barley.csv       real barley field, one variety, for Exercise 0
  data/entries_template.csv        example entries for Exercise 2
