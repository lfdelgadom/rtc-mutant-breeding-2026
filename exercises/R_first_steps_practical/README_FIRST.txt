GETTING STARTED WITH R AND RSTUDIO: PRACTICAL SESSION (RTC RER5030, Pre-course Session 1)

1. Double click R_first_steps.Rproj (opens RStudio inside this folder).
2. Run install_packages.R once (needs internet).
   No R on your computer? Use Posit Cloud (see the slides) and upload this folder.
3. Open R_first_steps.Rmd and work chunk by chunk. Chunks called "Your turn" are empty: write your code there.
4. At the end click Knit to make your own HTML report.

Time: about 50 minutes.

Files
  R_first_steps.Rmd          the practical
  install_packages.R         installs the 5 packages that are needed
  data/precourse_trial.csv        comma separator, decimal point
  data/precourse_trial_eu.csv     semicolon separator, decimal comma
  data/precourse_trial.xlsx       Excel file
  data/precourse_trial_dictionary.csv   description of each column
  data/Example_rice.csv           accents in an old encoding (latin1)
