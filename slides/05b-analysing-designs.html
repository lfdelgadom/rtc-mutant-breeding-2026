380 lines, 2 replicates, 18 blocks of 22 plots (11 rows by 2 columns) per replicate.

Reading the alpha-lattice model

Yijk = μ + Ri + Bj(i) + Gk + εijk

  • Yijk: observed response (yield) of genotype k, in block j of replicate i
  • μ: overall mean
  • Ri: effect of replicate i
  • Bj(i): effect of incomplete block j within replicate i. It only removes field variation, so it goes in brackets in R
  • Gk: effect of genotype k, what we compare
  • εijk: experimental error, what the model cannot explain
lmer(yield ~ rep + (1 | rep:block) + gen, data = john.alpha)
  • rep:block: block 1 of replicate 1 is not block 1 of replicate 2

Write rep:block, never block alone.

Does the row-column model remove field variation?

m_rcbd   <- lm(yield ~ rep + geno, data = wh09)
m_rowcol <- lmer(yield ~ rep + geno + (1 | rep:row) + (1 | rep:col), data = wh09)

c(RCBD = sigma(m_rcbd)^2, row_column = sigma(m_rowcol)^2)   # residual variance
      RCBD row_column 
 0.3130188  0.1632631 
print(VarCorr(m_rowcol), comp = "Variance")
 Groups   Name        Variance
 rep:row  (Intercept) 0.034546
 rep:col  (Intercept) 0.110355
 Residual             0.163263
  • Residual variance falls from 0.31 to 0.16
  • Most field variation is between columns (0.110); rows add less (0.035)
  • Part of what the RCBD called “error” was field variation. The row-column model removes it, so genotype comparisons are more precise.

row or rep:row?

In WH09 the row numbers 1 to 34 are used in both replicates.

  • (1 | row) treats row 5 of replicate 1 and row 5 of replicate 2 as the same block
  • They are in different parts of the field
  • In a resolvable design, rows and columns are nested in replicates:
(1 | rep:row) + (1 | rep:col)

Or number rows and columns so that each is unique in the field.

Block 2

From layout to model

The design determines the model

Design Model
CRD Yik = μ + Gk + εik
RCBD Yik = μ + Ri + Gk + εik
Augmented Yjk = μ + Bj + Gk + εjk
Alpha-lattice Yijk = μ + Ri + Bj(i) + Gk + εijk
Resolvable row-column Yijlk = μ + Ri + Rowj(i) + Coll(i) + Gk + εijlk
p-rep Yjlk = μ + Rowj + Coll + Gk + εjlk

μ overall mean, G genotype, R replicate, B incomplete block, Row and Col row and column, ε error. “j(i)”: j within i.

The same models in R

# a term in brackets only removes field variation (explained on Day 3)
lm(y ~ geno)                                                  # CRD
lm(y ~ rep + geno)                                            # RCBD
lm(y ~ block + geno)                                          # Augmented
lmer(y ~ rep + (1 | rep:block) + geno)                        # Alpha-lattice
lmer(y ~ rep + (1 | rep:row) + (1 | rep:col) + geno)          # Resolvable row-column
lmer(y ~ geno + (1 | row) + (1 | col))                        # p-rep (plus spatial term)

Each term of the equation is one term of the formula: rep is R, rep:block is Bj(i), geno is G.

One model per design

  • Genotypes (gen, TREATMENT) and replicates (rep): the terms we use to compare
  • (1 | ...): blocks, rows and columns. They are only there to remove field variation; we never compare them. Models with a term like this are called mixed models (Day 3)
  • Rows and columns are nested in replicate: rep:row
fit_crd    <- lm(yield ~ TREATMENT, data = d_crd)
fit_rcbd   <- lm(yield ~ REP + TREATMENT, data = d_rcbd)
fit_alpha  <- lmer(yield ~ REP + (1 | REP:IBLOCK) + TREATMENT, data = d_alpha)
fit_rowcol <- lmer(yield ~ REP + (1 | REP:rowf) + (1 | REP:colf) + TREATMENT, data = d_rowcol)

Three rules

  • Replicates (complete blocks): every genotype is in every replicate, so they enter the model as ordinary terms
  • Incomplete blocks, rows, columns: a genotype is not in every block, so part of the information about genotypes is also between blocks. Writing them in brackets, (1 | block), lets the model use it.
  • Genotypes: to compare and select them we keep them as ordinary terms. Tomorrow (Day 3) we see the other option and what it is good for.

Exercise

Exercise (homework): john.alpha

Context. A real spring oats trial from Craibstone, Aberdeen (John and Williams, 1995): 24 varieties, alpha-lattice, 3 replicates of 6 blocks of 4 plots. The question: what do we gain by analysing it as an alpha-lattice instead of an RCBD?

  1. Check the design: plots per replicate, blocks, plots per block
  2. Fit the RCBD model and the alpha-lattice model. Compare residual variance and average SED
  3. Generate a new alpha-lattice for the same trial with FielDHub
  4. Write your findings

Homework. File: Exercise3_john_alpha.Rmd in the ZIP

Solution

john.alpha |> count(rep, block) |> count(rep, plots_per_block = n)
  rep plots_per_block n
1  R1               4 6
2  R2               4 6
3  R3               4 6
oats_rcbd  <- lm(yield ~ rep + gen, data = john.alpha)
oats_alpha <- lmer(yield ~ rep + (1 | rep:block) + gen, data = john.alpha)

c(rcbd_residual_variance = sigma(oats_rcbd)^2, alpha_residual_variance = sigma(oats_alpha)^2)
 rcbd_residual_variance alpha_residual_variance 
             0.13458596              0.08522511 
sed_gen <- function(fit) {
  V <- vcov(emmeans(fit, "gen", lmer.df = "asymptotic")); n <- nrow(V)
  sqrt(2 * (mean(diag(V)) - (sum(V) - sum(diag(V))) / (n * (n - 1))))
}
c(rcbd = sed_gen(oats_rcbd), alpha = sed_gen(oats_alpha))
     rcbd     alpha 
0.2995396 0.2647806

Residual variance falls from 0.135 to 0.085, average SED from 0.30 to 0.26 t/ha. Ignoring the blocks throws away information.

Key takeaways

  • A smaller residual variance gives a smaller SED: the alpha-lattice and the row-column design detect smaller differences with the same plots
  • The design determines the model: replicates, blocks, rows and columns within replicates; incomplete blocks, rows and columns go in brackets, (1 | ...)
  • Write rep:block, never block alone, when block numbers repeat in each replicate
  • Keep the row and column of every plot: they are needed for the model
